</div>

---

## ✨ Características Principales

* **Búsqueda en tiempo real:** Consulta el clima introduciendo el nombre de cualquier ciudad del mundo.
* **Datos meteorológicos detallados:** Visualización de temperatura actual, sensación térmica, humedad, presión atmosférica y estado del cielo.
* **Iconografía dinámica:** Cambios visuales en los iconos según las condiciones climáticas (lluvia, despejado, nubes, nieve).
* **Manejo de errores:** Alertas visuales intuitivas si la ciudad introducida no existe o hay problemas de conexión.
* **Diseño Responsive:** Interfaz adaptada tanto para ordenadores como para dispositivos móviles.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5 / CSS3:** Estructura y diseño de la interfaz de usuario con estilos modernos.
* **JavaScript (ES6+):** Lógica de la aplicación, manipulación del DOM y consumo de la API mediante `fetch` y promesas (`async/await`).
* **OpenWeatherMap API:** Proveedor externo de datos meteorológicos en formato JSON.

## 🚀 Instalación y Configuración Local

Para poner en marcha este proyecto en tu equipo local, sigue estos sencillos pasos:

1. **Clona el repositorio:**
   ```bash
   git clone https://github.com/TheeWiick/Weather-App.git

2. Obtén tu API Key gratuita:

        Regístrate en OpenWeatherMap.

        Genera tu clave de API (API Key desde tu perfil).

3. Configura tus credenciales:

        Abre el archivo de configuración o el script de JavaScript donde se realizan las peticiones.

        Reemplaza la variable de la clave por tu API Key:
        JavaScript

        const API_KEY = 'TU_API_KEY_AQUÍ';

4. Ejecuta el proyecto:

        Abre el archivo index.html en tu navegador web preferido o utiliza una extensión como Live Server en VS Code.
